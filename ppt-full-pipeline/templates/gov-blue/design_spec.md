## 二、设计规范

### 2.1 配色方案：政务深蓝系

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色-深蓝 | `#2F5597` | 封面主块、页眉导航条、底部结论条 |
| 辅色-中蓝 | `#4874CB` | 渐变过渡、边框、图标 |
| 深海军蓝 | `#05497F` / `#034581` | 标题栏、平行四边形装饰 |
| 卡片蓝 | `#2E54A1` / `#3C609E` | 卡片标签、重点区块 |
| 边框蓝 | `#3D68BF` | 组织架构卡片边框 |
| 文字蓝 | `#4264A0` / `#1F4D92` | 卡片内文字 |
| 强调红 | `#C00000` | 关键词高亮、重点标注 |
| 背景白 | `#FFFFFF` | 封面底、卡片底 |
| 装饰蓝 | `#B6C7EA` | 箭头连接线、虚线 |
| 浅蓝底 | `#2F5597` 10-17%透明度 | 卡片浅底 |

### 2.2 渐变系统

本模板大量使用渐变，是区别于「纯色政务风」的核心特征：

| 渐变 | 用途 |
|------|------|
| `#2F5597 → #4874CB(58%)` | 顶部导航条（含drop-shadow） |
| `#034581 → #6CAFEF` | 左侧平行四边形装饰 |
| `#6CAFEF(50%) → #FFF(0%)` | 平行四边形高光装饰 |
| `#2F5597(79%) → #2F5597 → #2F5597(79%)` | 章节标题条 |
| `#0676FE(18%) → #0162D7(7%)` | 卡片浅底（含drop-shadow） |

### 2.3 字体规范

```
font-family: "微软雅黑", "方正小标宋_GBK", "方正楷体_GBK", "Times New Roman", sans-serif
```

| 层级 | 字号 | 字重 | 字体 | 用途 |
|------|------|------|------|------|
| 封面主标题 | 72pt | bold | 方正小标宋_GBK | 封面标题 |
| 封面署名 | 37pt | bold | 方正楷体_GBK | 封面单位/日期 |
| 一级标题 | 37pt | bold | 微软雅黑 | 页面大标题 |
| 二级标题 | 32pt | bold | 微软雅黑 | 子标题 |
| 三级标题 | 24pt | bold | 微软雅黑 | 卡片标题/结论 |
| 正文 | 21pt | bold | 微软雅黑 | 卡片内容 |
| 小字 | 18.67pt | bold | 微软雅黑 | 标签/细节 |

### 2.4 布局规范

| 区域 | 说明 |
|------|------|
| 顶部导航条 | 0-69px，渐变蓝底，37pt白色标题 + 左侧平行四边形装饰 |
| 子标题条 | 80-140px区间，渐变蓝底，32pt白色二级标题 |
| 内容区 | 140-600px，白色卡片 + 图文混排 |
| 底部结论条 | 600-660px，圆角深蓝底 `#2F5597`，24pt白色结论文本 |
| 左侧装饰 | 平行四边形 `#034581` + `#6CAFEF` 渐变，左上角 |
| 卡片圆角 | 3-10px |
| 卡片阴影 | `feDropShadow` dx=2-10 dy=2-10 blur=2-16，蓝调 `#2E54A1`/`#0162D7` |

### 2.5 设计DNA（区别于普通政务风的6个特征）

1. **渐变而非纯色**：所有色块均使用线性渐变，绝不用纯色
2. **平行四边形装饰**：左上角必有 `#034581→#6CAFEF` 渐变平行四边形
3. **蓝调阴影**：所有卡片阴影为蓝色系而非灰色（`#2E54A1`、`#0162D7`）
4. **红字高亮**：关键术语用 `#C00000` 红色标注
5. **底部结论条**：每页底部必有圆角深蓝底白色结论文本
6. **全粗体**：所有文字均为 bold，无常规字重

## 三、配图逻辑（核心分析）

### 3.1 图片类型分布

| 类型 | 数量 | 占比 | 使用场景 |
|------|------|------|----------|
| **矢量图(SVG)** | 10个 | 33% | 组织架构图、流程图、风险评估模型、箭头连接线、装饰图标 |
| **截图(PNG)** | 20个 | 67% | 平台界面截图、数据看板、地图、表格、系统演示 |

### 3.2 配图功能分类

| 功能 | 说明 | 示例 |
|------|------|------|
| **结构图** | 组织架构、层级关系 | 融合办公工作组架构（7个部门竖排卡片） |
| **流程图** | 业务流程、步骤推进 | DLEC风险评估模型（天气→温度→位置→人流量→设施运行→输出） |
| **截图实证** | 平台界面、数据结果 | 风险管控系统截图、交通拥堵分析界面 |
| **数据展示** | 表格、图表、指标卡 | 风险点统计表、重点区域分布 |
| **装饰图标** | 圆圈+图标、箭头连接 | 椭圆节点、虚线连接线、箭头标记 |

### 3.3 配图布局模式（3种核心模式）

#### 模式A：左侧文字+右侧配图（60/40分栏）
```
┌──────────────────────────────────┐
│ 顶部导航条（渐变蓝）              │
├──────────────────────────────────┤
│ 子标题条（渐变蓝）                │
├──────────────┬───────────────────┤
│ 文字说明      │  截图/图表         │
│ · 要点1      │  [PNG]            │
│ · 要点2      │                   │
│ · 要点3      │                   │
├──────────────┴───────────────────┤
│ 底部结论条（深蓝圆角）            │
└──────────────────────────────────┘
```
> 使用页：Slide 3, 5, 7

#### 模式B：上方流程图+下方卡片网格
```
┌──────────────────────────────────┐
│ 顶部导航条（渐变蓝）              │
├──────────────────────────────────┤
│ 子标题条（渐变蓝）                │
├──────────────────────────────────┤
│ 流程图/概念图（SVG手绘）          │
│  ┌─┐ → ┌─┐ → ┌─┐ → ┌─┐       │
│  │A│   │B│   │C│   │D│       │
│  └─┘   └─┘   └─┘   └─┘       │
├──────────────────────────────────┤
│ 卡片1  │ 卡片2  │ 卡片3  │ 卡片4 │
├──────────────────────────────────┤
│ 底部结论条（深蓝圆角）            │
└──────────────────────────────────┘
```
> 使用页：Slide 6, 8

#### 模式C：全幅组织架构图
```
┌──────────────────────────────────┐
│ 顶部导航条（渐变蓝）              │
├──────────────────────────────────┤
│ 引文条（浅蓝底+深蓝文字）         │
├──────────────────────────────────┤
│        组织结构图(SVG)            │
│     ┌──────────────┐             │
│     │  总牵头单位    │             │
│     └──┬──┬──┬──┬──┘             │
│       A  B  C  D  E              │
│     ┌──┴──┴──┴──┴──┐             │
│     │   人员编制     │             │
│     └──────────────┘             │
├──────────────────────────────────┤
│ 底部结论条（深蓝圆角）            │
└──────────────────────────────────┘
```
> 使用页：Slide 2

### 3.4 配图核心规则

1. **封面不用图**：封面纯文字+色块，无背景图
2. **每页下部必有结论条**：深蓝圆角底+白色文字，总结本页核心观点
3. **图不压文**：配图与文字分区明确，互不重叠
4. **SVG手绘优先**：组织架构、流程、模型用SVG矢量绘制，不依赖外部图片
5. **截图作实证**：PNG截图用于展示系统界面和数据结果
6. **装饰克制**：只用平行四边形和渐变，不用图标、照片、插画
7. **蓝色系统一**：所有配图边框、箭头、连接线均为蓝色系

## 四、内容大纲（9页）

### P01 封面
- 白底 + 居中 `#2F5597` 深蓝矩形（1210×325px）
- 白色72pt标题（方正小标宋_GBK）居中
- 底部署名区：深蓝37pt（方正楷体_GBK）

### P02 背景与组织架构（模式C）
- `#2F5597` 满版背景 + 白色内卡片（1220×614px）
- 引文条：浅蓝底17% + 深蓝29pt文字
- 组织架构图：竖排部门卡片+人员编制行
- 圆形节点+箭头连接

### P03 风险管控总览（模式A）
- 左侧：标题+要点文字
- 右侧：截图/图表（2张PNG）
- 底部结论条

### P04 风险评估模型（模式B）
- DLEC模型流程图（椭圆节点→连接线→输出框）
- 红色标注"各类自然、人为风险因子"
- 底部结论条

### P05 业务上平台总览（模式A）
- 左侧：截图
- 右侧：文字要点

### P06 业务上平台流程（模式B）
- 三层卡片：全要素感知→全流程协同→全场景智治
- 5步流程节点+箭头连接
- 底部结论条

### P07 业务上平台成果
- 单张数据截图+文字说明

### P08 交通拥堵治理（模式B）
- 流程图+文字说明
- 底部结论条

### P09 封底
- 深蓝渐变底
- 总结文字+署名
