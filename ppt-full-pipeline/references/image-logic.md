# Consulting-Blue Template 配图逻辑

从顶级咨询风模板（20页）制作过程提炼。

## 三种配图布局模式

### 模式 A：左侧文字 + 右侧配图（60/40）
- 左侧：标题 + 卡片要点
- 右侧：实景照片或结构图（520×480px）
- 适用：现状描述、数据展示、案例页

### 模式 B：上方流程图 + 下方卡片网格
- 上方：流程/概念图
- 下方：三层卡片 + 箭头连接
- 适用：重点任务、业务流程、阶段目标

### 模式 C：全幅背景图
- 全页 1280×720 实景照 + 深蓝半透明遮罩
- 中央大标题 + KPI 卡片
- 适用：封面、章节页、封底

## 配图类型分流

| 页面类型 | 配图类型 | 来源 | 示例关键词 |
|----------|----------|------|-----------|
| 封面/封底 | 母版底图（城市实景） | Unsplash搜索 | Chongqing cityscape, skyline |
| 现状描述 | 意向照片（街景/道路） | Unsplash搜索 | 重庆 滨江 步道 |
| 流程/架构 | 结构示意图 | 手绘SVG或DALL-E | government planning diagram |
| 数据展示 | 数据图表 | matplotlib | — |
| 政策/原则 | 纯文字卡片 | 无需配图 | — |

## 内容匹配原则

配图必须与页面内容有对应关系，通用配图宁可不用：
- 封面 → 城市全景 ✓
- 净（净化水面江岸）→ 滨江水岸 ✓
- 连（连接林冠线灯饰）→ 洪崖洞夜景 ✓
- 指导思想 → 滨江照 ✗（应无图）
- 工作原则 → 城市风景 ✗（应用结构框架图）
- 保障措施 → 通用街景 ✗（应用结构图）

## 搜索引擎教训

- Unsplash 比 cn.bing.com 更可靠（curl 直接下载）
- `browser_navigate` 不支持中文URL
- 下载后必须 `file` 验证 JPEG 有效性（很多 Unsplash URL 返回 404 HTML 页面）
