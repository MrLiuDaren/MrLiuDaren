# Hermes Agent Skills

Shared skills for [Hermes Agent](https://hermes-agent.nousresearch.com/docs).

## Skills

| Skill | Description |
|-------|-------------|
| [ppt-full-pipeline](ppt-full-pipeline/SKILL.md) | 7-Agent complete PPT generation pipeline from source document to professional PPTX |

## Usage

Copy any skill directory to your Hermes skills folder:

```bash
cp -r ppt-full-pipeline ~/AppData/Local/hermes/skills/productivity/
```

Restart Hermes and the skill will be auto-discovered.
